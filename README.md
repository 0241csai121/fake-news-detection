# Fake News Detection System

## Overview

Fake News Detection System is a Deep Learning and Natural Language Processing project that classifies news articles as **Real** or **Fake**.

The project uses deep learning models to learn patterns from news text and predict its class.

## Features

* Fake and real news classification
* Natural Language Processing
* Text preprocessing
* Deep Learning based classification
* LSTM model
* BERT Transformer model
* Model training and evaluation

## Technologies Used

* Python
* PyTorch
* NLP
* LSTM
* BERT
* Pandas
* NumPy
* Scikit-learn
* Google Colab

## Dataset

The project uses two datasets:

* `Fake.csv` — Fake news articles
* `True.csv` — Real news articles

## Models Used

### LSTM

An LSTM-based deep learning model is used to learn sequential patterns in news text.

### BERT

A BERT-based Transformer model is used to capture contextual information from the input text.

## Project Workflow

1. Dataset loading
2. Data preprocessing
3. Text tokenization
4. Vocabulary creation
5. Sequence preparation
6. Model training
7. Model evaluation
8. News classification
